# /dev - Mode Développement

Lance Léon en mode développement avec hot-reload.

## Instructions

1. Se placer dans le répertoire: `cd C:\Users\Marc\projets\leon`
2. Lancer: `npm run tauri dev`
3. Frontend sur http://localhost:5173
4. L'app Tauri s'ouvre automatiquement

## Notes

- Hot-reload pour le frontend Svelte
- Rebuild Rust nécessaire pour changements backend
- Logs dans la console
