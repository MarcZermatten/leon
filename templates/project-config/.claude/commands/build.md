# /build - Compiler Léon

Compile l'application Tauri pour production.

## Instructions

1. Se placer dans le répertoire: `cd C:\Users\Marc\projets\leon`
2. Compiler: `npm run tauri build`
3. L'exécutable sera dans `src-tauri/target/release/`
4. Rapporter les erreurs si échec

## Notes

- Build Windows uniquement (pas de cross-compile)
- Prend environ 2-5 minutes
- Nécessite Rust toolchain installé
